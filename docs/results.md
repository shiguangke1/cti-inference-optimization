## 如何阅读数字

- AUC/PCOC 变化意味着数值路径或校准发生变化，不能只看时延。
- 线上 GPU 存在运行噪声，小于约 0.1s 的单次差异不宜过度解释。
- cached-batch profile、DataLoader profile 和线上计时必须分别标注，不能混为同一口径。
- 最终结论以完整端到端线上反馈为准。
